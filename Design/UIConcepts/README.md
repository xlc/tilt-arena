# UI concept references

These generated boards informed the SpriteKit UI; they are not shipped as
full-screen images. Current snapshots in `TiltArenaTests/__Snapshots__/` are
the implemented visual baseline.

- `home.png`: title/stat hierarchy and primary PLAY action.
- `mode-select.png`: mode availability and mission brief.
- `awards.png`: completed and active objectives.
- `weapon-codex.png`: weapon silhouettes and role colors.
- `options.png`: grouped controls and isolated reset.
- `calibration.png`: live tilt preview and neutral target.
- `developer-tuning.png`: grouped tuning controls.
- `pre-run.png`: hold-to-launch guidance.
- `gameplay.png`: compact HUD direction.
- `pause.png`: primary resume action and secondary utilities.
- `post-run.png`: score hierarchy and immediate replay.
